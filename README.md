# Drone Deliveries

A project on the .NET platform for managing a drone delivery company. It utilizes a three-tier architecture and implements design patterns such as Singleton, Factory, and Contract Design. The project incorporates threading via Background Worker to simulate real-time delivery execution and uses XML files for the database. The user interface is developed with WPF, using XAML for the UI, C#, and LINQ for database operations, and follows the MVVM (Model-View-ViewModel) pattern.

## Features

- **Three-Tier Architecture:** Organized structure separating presentation, business logic, and data access layers.
- **Design Patterns:** Singleton, Factory, and Contract Design patterns for efficient code management and flexibility.
- **MVVM Pattern:** Model-View-ViewModel pattern used to separate concerns and enhance maintainability.
- **Real-Time Simulation:** Real-time delivery execution simulation using threading (Background Worker).
- **Database:** XML files used for database storage and management.
- **User Interface:** Developed with WPF, employing XAML for the UI and C# with LINQ for database interactions.
